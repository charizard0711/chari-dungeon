# 26〜30F ボス・マップ提案

2026-09-13。ユーザーの「26Fから属性をばらばらにし、30Fは全属性の大きなドラゴン、雑魚は少なめ」という希望に対する比較用の提案。

## ボスとマップ

- **26F：深海魔クラーケン（水）** — 深海の封殿。触手の直線叩きつけと、1列ずつ迫る水の波。予告を見て横へ逃げる戦い。
- **27F：獄炎騎士ヴァルゼオン（火）** — 黒鉄の熔炉。大剣の扇形斬りと、予告した2本の炎の列。振り下ろした後は2ターンの反撃時間。
- **28F：氷華女帝セレネ（氷）** — 氷華の宮殿。氷槍が予告した列に伸びる。次に外側から迫る霜の輪を、空いている通路へ避ける。
- **29F：虚空魔眼アビスロード（闇）** — 虚空の祭域。視線の直線ビームと、時間差で開く闇の円。光る瞳と床の予告で次の技を知らせる。
- **30F：万象竜皇アストラヴェイン（火・水・氷・雷・闇）** — 万象の竜座。前半は5属性を1種類ずつ、後半は2種類を組み合わせる。核の色と属性マークで予告。必殺「万象終焉」は安全地帯を残した連続攻撃にし、終了後は大きな反撃時間。

## 大きさと敵の数

- 26〜29Fの中ボス部屋は10×10を基本に、4〜6個の低い置物を外周へ配置する。
- 30Fは24×18程度の八角形の専用部屋。翼幅8〜10マス、胴体の当たり判定は3×3を目安にする。
- ドラゴンの足元・主人公・予告マスを見渡せるよう、30Fの戦闘ではカメラを少し引く。
- 26〜29Fの道中の雑魚は従来の半分程度。同時に相手をする数は2〜3体を目安にする。
- 26〜28Fの中ボス部屋は雑魚0〜1体。29・30Fのボス部屋はボス1体にし、30Fは追加の雑魚召喚も行わない。
- 雑魚を減らした分の経験値は、ボスの報酬に寄せる案。
- 30Fが使う全属性は、現在のゲームの火・水・氷・雷・闇。核の色と属性マークで次の攻撃を示す。前半は1属性ずつ、後半は2属性を組み合わせる。
- ボスは4方向の絵を基本にし、移動と小さな姿勢変化を滑らかにする。巨大竜も毎回伸縮する表現にはしない。
