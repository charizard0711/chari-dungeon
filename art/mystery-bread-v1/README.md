# ふしぎパン

承認された第3案（クロワッサン）を採用。既存のポーション・復活の種に合わせたドット絵。
imagegen元 exec-d6434721-3c93-4cfb-ac50-e033927824d8.png、参照 exec-0fde959c-ebcd-4113-b87f-a4b827856f73.png。
プロンプト: 左下第3案のみ、金茶色のクロワッサンと小さな金のきらめき、同じドット密度と輪郭、透明背景、番号・UI・文字なし。
256px透明lossless WebPとして public/assets/items/mystery-bread-v1.webp に保存。

通常MOB（エリート含む）の独立2%抽選。ボス・フロアボス・福袋うさぎ除外。通常ドロップ半減の倍率は掛けない。箱・樽には追加しない。
赤枠、床上は小さな金色の光がゆっくり明滅。
使用でHP最大、所持する全武器・盾の耐久最大、強化値必ず+1。装備中と所持リストの同一参照は重複させない。服・鎧には耐久値がない。1個消費、1ターン。
セーブ・復元・図鑑・売却に既存アイテム共通処理を使用。
検証: qa-mystery-bread.cjs、npm run build。
