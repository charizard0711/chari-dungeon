当初の提案画像の21Fと25Fのボスを、ユーザー指定で入れ替えた。ボスはいずれも雷属性。25Fの専用ボス部屋もライガに変更した。

## 画像と制作方法

- 内蔵 ImageGen で制作。指示、参照画像、生成元は [prompts.json](prompts.json) に記録。
- 各ボスは下・左・右・上の4方向。ネイティブの透明背景を保持。
- ライガのみ背景の透明化を ImageGen の編集で実施。編集指示も記録。
- 床は各階4種類。壁は各階2種類、置物は各階4種類。
- 壁は縦横ともつながる正方形の占有範囲と短い前面で描き直した。
- 原画はこのフォルダーのPNG。ゲーム用画像は `public/assets/terrain/thunder-v1/`、`public/assets/monsters/`、`public/assets/monsters/directional/`。
- `scripts/prepare-thunder-assets.cjs` は原画の切り出し・縮小・配置だけを行う。背景除去や描き足しは行わない。

## ゲーム内の動作

- 21〜24Fは既存の10×10中ボス部屋を使用し、6〜8個の置物を配置。中央と入口の通路を確保。
- 25Fの専用ボス部屋は16×14の角を切った形。周辺に8個の遮蔽物を置き、中央の縦横は空けた。
- 21Fは前方への帯電した顎、22Fは扇形の放電、23Fは間に逃げ道のある二重の雷撃帯、24Fは外側→内側の時間差落雷。
- 25Fは直線突進と十字落雷。突進回避後に反撃の隙ができる。
- 4方向の絵と既存の滑らかな移動・小さな姿勢変化を使用。大きさを変えるアニメーションや大量の追加フレームは使用しない。
- 床の模様の選択は固定の座標ハッシュ。通常のゲーム乱数に影響しない。壁は開始時に一度合成し、描画中に合成し続けない。

## 確認済み

- `npm run build`
- `node scripts/qa-custom-floor-bosses.cjs`：21〜25Fのボス配置、属性、攻撃予告、遮蔽物、反撃の隙、突進の完了待ち。
- `node scripts/qa-frost-decor.cjs`：全30階・750マップ・17,306個の置物。通路、入口、部屋中央、25Fの部屋形状を確認。
- `node scripts/qa-movement-input.mjs`：先行入力、長押し、4方向、連続した姿勢変化、移動と攻撃の待ち時間。
- `node scripts/qa-thunder-assets.cjs`：46個のゲーム用画像の存在と寸法、4方向の欠け・はみ出し、ボスと置物の透明背景。
- 開発ブラウザーで21〜25Fの表示、21〜24Fで方向キーの移動と25Fのコンソールを確認。

素材の再作成と画像検証には Sharp が必要。プロジェクト外の既存インストールを使う場合は `SHARP_MODULE` にモジュールの絶対パスを指定する。
