# 装備の4方向表示と15階・20階の入れ替え

2026-09-12。ローカル実装。公開リリースは行っていない。

## 装備の描画

- 既存の男女×服5種、計10枚の体のスプライトシートを再利用。
- 武器46種・盾9種をそれぞれ4方向に描き、合計55シート／220方向フレームを追加。
- キャラの手の位置に武器と盾の2枚を重ねる。二刀流では盾側にも剣を表示する。
- 待機、歩行、攻撃、被弾と向きに合わせて位置・重なりを更新。武器を振る角度は補間し、弓・銃は狙う向きを維持する。
- 左向きの攻撃は右向きの体の攻撃セルを反転して使用。
- 装備変更時に画像を生成せず、2個の画像オブジェクトを再利用。装備パネルにも同じ描画方式を使用。

## 保存先と生成記録

- ゲーム用画像: `../../public/assets/equipment/directional/*.png`。各128×128px、64×64pxの4セル。順序は正面・左・右・背面。
- 55シート合計501,356バイト。展開後のRGBAテクスチャは3,604,480バイト。
- 原寸の最終生成画像: このフォルダーの各装備キーのPNG。
- 最終プロンプトセットと参照元: 各装備キーのJSON。`prompt`に生成指示、修正がある場合は`alphaPrompt`・`correctionPrompt`に追記。`source`は採用した最終出力を示す。
- 生成方式: **built-in ImageGen**。既存の武器・盾アイコンをデザイン参照に、透明背景の4方向アトラスを生成。
- `jobs.json`: 全55装備と既存アイコンの対応。
- `preview-0.png`～`preview-2.png`: 最終ゲーム画像の確認用一覧。並び順は`jobs.json`と同じ。
- `scripts/prepare-held-equipment.cjs`: 透明画像の切り出し・等比縮小・配置のみ。描画や背景削除は行わない。

## ボスと報酬

- 15階の専用部屋: 氷晶王ベヒーモス、氷晶震撃、八角形の氷の部屋と氷オブジェクト。
- 20階の専用部屋: 炉心王タイタン、炉心攻撃、柱のある鍛冶区の部屋。
- 基本のHP・攻撃力・防御力は移動先の階層に合わせて維持。
- 15階の専用ボス撃破で通常の武器報酬を置き換え、氷属性武器を必ず1本落とす。
- 候補は15階までに解禁される「氷晶シラユキ」「凍界剣グレイシア」「氷月弓ルナフロスト」「氷銃フロストロック」の4種。各25%。耐久度は満タン、既存のボス報酬強化値を適用。
- 重複した撃破通知による追加ドロップを防止。服などの既存報酬は維持。
