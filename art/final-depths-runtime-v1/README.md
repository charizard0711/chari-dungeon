# 26–30F 実装用アート

承認された `../final-depths-concepts-floors26-30-v1/` を元にした、ゲーム用の実画像と実装。

| 階 | ボス | 属性 | 地形 |
|---|---|---|---|
| 26 | 深海魔クラーケン | 水 | 深海の祭壇、濡れた石、貝・珊瑚・錨・水盤 |
| 27 | 獄炎騎士ヴァルゼオン | 火 | 獄炎の鍛冶宮、黒鉄と火山岩、金床・鎖・火鉢 |
| 28 | 氷華女帝セレネ | 氷 | 氷華の宮殿、氷の低壁、結晶・玉座・氷花 |
| 29 | 虚空魔眼アビスロード | 闇 | 虚空の回廊、黒曜石、壊れた石輪・碑・紫水晶 |
| 30 | 万象竜皇アストラヴェイン | 火・水・氷・雷・闇 | 万象の竜座、白金の低壁、五属性の祭壇・崩れた竜像 |

ボスは下・左・右・上の4枚。26–29Fは128pxフレーム、30Fは256pxフレーム。固定倍率のまま既存の連続補間で移動し、軽い揺れ・踏み込みを加える。

30Fの翼幅は約9タイル、接触・移動判定は胴体の3×3タイル。24×18の角を切った広間を固定カメラで映す。五属性の攻撃を数字と色で予告し、HP半分から二属性連携、一定周期で「万象終焉」。全攻撃列に到達可能な避難マスを残し、大技後は3ターンの隙を作る。

26–29Fの通常の雑魚配置は15体から8体。中ボス部屋は10×10、4種類の装飾と2個の容器。雑魚は部屋に侵入しない。30Fは短い道中に2体、専用広間は竜皇1体。終盤のボス部屋では長期戦の追加出現を停止。ボス経験値を増やして道中の減少を補う。最深部の扉を通って竜皇を倒した後にクリアする。

## 再生成・検証

- 生成は組み込みImageGen。原案と出力元、全プロンプトは `prompts.json`、透過修正は `alpha-corrections.json`、採用元は `manifest.json`。
- 切り出し・縮小・配置のみ `scripts/prepare-final-depths-assets.cjs`。背景除去・再描画はスクリプトで行わない。Sharpは `SHARP_MODULE` で指定可能。
- `node scripts/qa-final-depths.cjs`: 出現数、胴体判定、壁・祭壇、進行、属性別ダメージ、予告・回復、6,480通りの回避経路。
- `node scripts/qa-final-depths-assets.cjs`: 48画像の寸法・ネイティブ透過・余白・容量（合計約1.56MiB）。
- 既存の `qa-custom-floor-bosses.cjs`、`qa-frost-decor.cjs`、`qa-movement-input.mjs` も使用。
- `npm run build` で型チェックと本番ビルド。

ローカル確認: `/?qa-game&qa-floor=26&qa-field-arena`（27〜29も同様）、`/?qa-game&qa-floor=30&qa-boss&qa-field-arena`。
