# Journal UI assets

Generated with the built-in image_gen tool. Original PNGs are kept here; the game loads the WebP copies in `public/assets/ui/journal-v1`.

## Modal frame

Use case: ui-mockup. Production raster game UI modal background for Japanese dark fantasy roguelike. Landscape 3:2 rectangular frame, front view perfectly flat no perspective. Match refined hand-painted gothic dragon frames: very dark charcoal obsidian nearly black quiet center (90% empty, no graphics or text inside), thin detailed SILVER grayscale metal border, beveled filigree, small corner faceted crystals, lower right small elegantly carved dragon head and a folded cloth, lower left tiny carved quill and closed ledger. All ornament restricted to outermost 3 percent so usable modal text is not obscured. Entire palette grayscale silver white and black, NO gold, NO red, NO blue, because game recolors by difficulty. Border extends exactly to all four image edges. Clean high quality painted fantasy game asset, not pixel art. No letters, no words, no UI fields, no grid, no mockup screen, no drop shadow outside. Opaque dark background.
