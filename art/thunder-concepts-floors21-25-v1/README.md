## 共通方針

- 腰程度の低い壁。床の模様と明暗差を控えめにし、明るい雷はボス・置物に集める。
- 21〜24Fは10×10の中ボス部屋を想定。中央4×4と縦横の経路を空け、端に6〜8個の置物。
- 25Fは16×14程度の八角形の専用部屋を提案。外周の外側に大きな避雷柱、戦闘範囲には低い小物。
- ボスは4方向の絵と滑らかな移動・小さな揺れ。画面全体の点滅や常時大量の雷エフェクトは使わない案。
- 装飾の水たまり・足跡・床模様は歩ける絵。危険な攻撃予告とは区別する。
- 25Fは写真を体型の参照とし、大きな頭、短い2本の前脚、強い後脚、長く太い尾を維持。濃紺の鱗と金色の雷紋を加える。
