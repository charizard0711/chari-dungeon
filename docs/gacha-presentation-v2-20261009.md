# ガチャ演出と所持金表示 v2

画像生成ツールで承認済みの3段階案を元に作成。背景の指示は「古い石造りの召喚部屋、深緑の旗、たいまつ、中央に空の台座、文字・装備なし」。アトラスの指示は「同じ金と青緑の宝箱の閉/開、魔法陣、光背、透過2×2」。原画とWebPはpublic/assets/ui/gacha-v2に保存。背景は幅800/quality88、627pxセルのアトラスは可逆WebP。

演出: 約0.7秒で召喚、約1.55秒で開封と装備表示、約2.1秒から受け取り可能。背景・宝箱・魔法陣・光背・粒子・装備を個別描画。S以上は光と粒子を増やす。抽選と装備付与は既存gachaPull、演出はその結果のアイコン・名称・等級・効果をそのまま表示する。受け取りは確認操作であり二重付与しない。500G、武器の各階上限、既存確率は維持する。

演出はモーダル内へマスクし、切替/連打を禁止。受け取り時・シーン停止時にタイマーとTweenと画像を解除。動きを減らす設定は演出短縮・粒子停止。日本語の長い効果説明を文字単位で折り返す。

PCはガチャを探索の上の専用カードにし500Gまでのゲージと残額を表示。スマホは下部ガチャを専用色と宝箱へ変更。所持金を太字金色へ拡大し増加分を浮かべる。500G到達時には探索画面で短い案内。

検証: scripts/qa-gacha-presentation.cjsはPC/スマホ、実際の500G消費、不足金額拒否、獲得名称/画像、全等級の演出、切替ロック、実マウスクリックによる受け取りと後片付けを確認。等級別演出検証には同じ実抽選結果のgradeのみを上書きするため、スクリーンショットのアイテム名に含まれる等級と大見出しは一致しない場合がある。本番では上書きしない。outputs/gacha-v2-20261009に各段階の画像。npm run buildも確認。未公開。
